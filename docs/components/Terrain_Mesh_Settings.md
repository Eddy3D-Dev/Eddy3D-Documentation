# ![](/images/icons/Terrain_Mesh_Settings.png) Terrain Mesh Settings - [[source code]](https://github.com/Eddy3D-Dev/Eddy3D/search?q=%22Terrain%20Mesh%20Settings%22)

![](/images/components/Terrain_Mesh_Settings-crop.png)

Configure mesh settings for terrain and underground regions. OutdoorPlus

#### Input

| Name | Nickname | Description | Type |
| ---- | -------- | ----------- | ---- |
| Surface Layer Count | SrfLC | Number of layers in the terrain surface. Optional; default is 4. | `Integer` |
| Surface Expansion Ratio | SrfER | Expansion ratio of terrain surface. Optional; default is 1.2. | `Number` |
| Soil Layer Count | SoLC | Number of layers in the terrain soil. Optional; default is 4. | `Integer` |
| Soil Expansion Ratio | SoER | Expansion ratio of terrain soil. Optional; default is 1.2. | `Number` |

#### Output

| Name | Nickname | Description | Type |
| ---- | -------- | ----------- | ---- |
| Terrain Mesh Settings | Mesh | Mesh settings for terrain and underground regions. | `Generic Data` |

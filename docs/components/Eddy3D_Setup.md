# ![](/images/icons/Eddy3D_Setup.png) Eddy3D Setup - [[source code]](https://github.com/Eddy3D-Dev/Eddy3D/search?q=%22Eddy3D%20Setup%22)

![](/images/components/Eddy3D_Setup-crop.png)

Opens the Eddy3D setup window: what each simulation capability needs, what is missing on this machine, and how to install it. Replaces the Install Engines components.

#### Input

| Name | Nickname | Description | Type |
| ---- | -------- | ----------- | ---- |
| Open | O | Open the setup window. | `Boolean` |

#### Output

| Name | Nickname | Description | Type |
| ---- | -------- | ----------- | ---- |
| Status | St | What the setup surface reports — the registered catalog, or why it could not open. | `Text` |

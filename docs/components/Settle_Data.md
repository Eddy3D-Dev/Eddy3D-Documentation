# ![](/images/icons/Settle_Data.png) Settle Data - [[source code]](https://github.com/Eddy3D-Dev/Eddy3D/search?q=%22Settle%20Data%22)

![](/images/components/Settle_Data-crop.png)

Hold the last output while the left mouse button is pressed, then publish the newest value when the button is released. Useful between an MD Slider and an expensive component.

#### Input

| Name | Nickname | Description | Type |
| ---- | -------- | ----------- | ---- |
| Data |  | Data to release only after the left mouse button is released. | `Generic Data` |

#### Output

| Name | Nickname | Description | Type |
| ---- | -------- | ----------- | ---- |
| Data |  | Last settled input data. | `Generic Data` |
